Лабораторная 4. Сравнение полиномиальной и сплайн интерполяции.
Рассмотрим функцию
$f(x)=\frac{1}{1+25x^2},\qquad x\in[-1,1]$.
Нужно исследовать, как выбор узлов и способ построения интерполянта влияют на точность приближения функции.
1. Полиномиальная интерполяция.
Самостоятельно реализуйте два способа построения интерполяционного многочлена: форму Лагранжа и форму Ньютона. Готовые функции полиномиальной интерполяции использовать нельзя. 
Сначала проведите расчеты на равномерных сетках
$x_j^{(n)}=-1+\frac{2j}{n},\qquad j=0,\ldots,n$,
для n=4,8,16,32,64, \dots. Сетки вложены: при удвоении n все старые узлы сохраняются. Затем повторите расчеты на вложенных сетках Чебышева при тех же значениях n.  Для каждой сетки сравните результаты форм Лагранжа и Ньютона. 
2. Кубический сплайн.
Для той же функции самостоятельно реализуйте кубический интерполяционный сплайн и исследуйте его на обеих последовательностях сеток из пункта 1. Используйте закрепленные граничные условия.
