### 2.2
Получилось что улучшенный метод достиг точности eps за 5 итераций, а обычный за 28. 
у обычного метода линейная сходимость и x_n/x_{n+1} = 0.5, у улучшенного x_n/(x_{n+1}**2) = 0.5

то есть, если знать кратность корня, то можно значительно ускорить решение.
